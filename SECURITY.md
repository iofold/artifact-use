# Security Policy

## Reporting a vulnerability

Email `opensource@iofold.com` with the subject `Artifact Use security report`.
Do not open a public issue.

Include the affected version or commit, impact, reproduction steps, and any
suggested mitigation. Remove credentials, customer data, and private artifact
content unless they are strictly necessary to understand the report.

We will acknowledge reports as soon as practical, coordinate investigation and
remediation privately, and credit reporters when requested and appropriate.

## Supported versions

Security fixes are made on the latest release and the `master` branch. Older
releases may require upgrading before a fix can be applied.

## Scope

This policy covers the code in this repository. Security issues in an
independently operated deployment remain the responsibility of that deployment,
though reports of upstream defects are welcome.
