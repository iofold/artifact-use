# Support

Use [GitHub Issues](https://github.com/iofold/artifact-use/issues) for
reproducible bugs and focused feature requests.

Include the Artifact Use version or commit, expected and observed behavior,
reproduction steps, and a sanitized description of your environment. Do not
post credentials, customer data, private artifact content, or deployment
identifiers.

Send suspected vulnerabilities privately to `opensource@iofold.com` as
described in [SECURITY.md](SECURITY.md).

Operational support for an independent deployment is the responsibility of
that deployment's operator.
