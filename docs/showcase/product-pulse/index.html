About this artifact — it is its own documentation

Unlike a single-file tool, this dashboard is a folder: an entrypoint, a stylesheet, a chart library, and two JSON datasets, published together as one immutable version behind one stable URL. The page below lists its own files — fetched live from the platform's machine descriptor (_au/index.json), the same endpoint agents use to read any artifact programmatically.

  • Multi-file publishing: relative imports (./lib/charts.js as an ES module, ./assets/style.css, fetch("./data/…")) just work.
  • Data viz: multi-series line chart with crosshair tooltips, donut, and bar lists — ~150 lines of dependency-free SVG.
  • localStorage: the theme toggle (◐) persists; range and series choices are per-visit state.
  • Machine-readable: everything an agent needs to inspect this artifact is one GET away.
